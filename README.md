# dw.pokemonzinho

# Contextualização

O *Digi Analyzer* é um site desenvolvido com o objetivo de reunir informações sobre os Digimons em um só lugar, por meio de cartões que apresentam seus respectivos dados. A plataforma busca facilitar a pesquisa e a exploração desse universo, atendendo tanto aos fãs da franquia quanto às pessoas que desejam conhecê-la.

Atualmente, o site permite pesquisar Digimons pelo nome ou pelo ID, exibindo suas informações, além de disponibilizar uma página com todos os Digimons para que os usuários possam explorar livremente. Para isso, o projeto utiliza HTML, CSS e JavaScript, integrados a uma API responsável por fornecer os dados apresentados na plataforma.
